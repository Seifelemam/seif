Voice recordings (optional)

Put recordings here (.mp3, .m4a, .wav or .ogg), then run:  python3 tools/sync_images.py
A "Hear my voice" box then appears by itself in Marketing -> Details -> Personal projects.

Naming: a file whose name ends in -en, -de or -ar is labelled by language, for example
    hello-en.mp3   hello-de.mp3   hello-ar.mp3     ->  English / Deutsch / العربية
Any other name is shown with the file name as its label.
While a recording plays, the background music dips automatically.
Keep files short (under about 1 minute each) so the page stays light.
